# Mode Admin

Tekan toggle di sebelah icon profile di pojok kanan atas untuk berganti ke mode Admin agar bisa melakukan operasi CRUD.

Sudah menggunkan fake API menggunakan Mock API dan dengan axios untuk mengelola data. hasil request dibagikan melalui State Management useContext.

Jika ingin dijalankan secara lokal dapat membuat file .env di root folder yang isinya seperti di dalam file .env.example
